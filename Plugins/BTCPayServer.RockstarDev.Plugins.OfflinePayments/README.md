# BTCPay Server Offline Payments Plugin

Adds offline / manual payment methods (ACH, Wire, Check) to BTCPay Server checkout.

## Features
- Per-store method configuration with bank details and payment instructions
- Customer acknowledgment flow at checkout
- Admin pending queue for manual settlement confirmation
- Auto-enables configured methods at checkout

## Supported Methods
ACH, WIRE, CHECK

## Requirements
BTCPay Server >= 2.3.6
